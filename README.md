# 和爸媽，慢遊上海

可直接部署至 GitHub Pages 的靜態網頁，不用安裝套件、不用 API 金鑰。

## 上傳與開啟

1. 在 GitHub 建立一個 repository（若公開，請只放可以公開的內容）。
2. 解壓縮本檔案包，把 **index.html、style.css、app.js、data.js、icon.svg、.nojekyll** 放到 repository 最外層。不要只上傳 ZIP，也不要多包一層資料夾。
3. Commit changes。
4. Settings → Pages → Build and deployment → Source 選 Deploy from a branch。
5. Branch 選 main、資料夾選 /(root)，按 Save。
6. 等 GitHub 部署完成，在 Pages 頁面開啟顯示的網址，通常是 https://你的帳號.github.io/儲存庫名稱/ 。

若手機看到舊內容，可重新整理或使用無痕頁面；本網站未加入會攔住更新的 Service Worker。

## 修改內容

- 每日行程、航班、住宿全部放在 **data.js**。直接在 GitHub 編輯、Commit，即可更新所有人看到的內容。
- 加入或刪除行程：修改當日 items 陣列。每站欄位為 time、title、note、place（選填，地圖搜尋字串）、type。
- 日期改動時也要同步 index.html 的標題、日期文字與航班資料。
- 網頁的每日備註與勾選清單只存於該瀏覽器 localStorage，**不會同步、不會寫回 GitHub**。清除瀏覽器資料後可能消失。公開內容請改 data.js。
- 地圖按鈕是依名稱搜尋，尚未確認分店的地點已註明。出發前請比對正確門牌，不能把搜尋結果當成已核實定位。

## 在網頁調整行程

每個行程最右側都有 ↑／↓，直接點即可調整同一天內的順序。第一站無法再上移，最後一站無法再下移。

順序會自動存在本裝置的瀏覽器，重新開啟仍保留；不會同步到家人手機。標示時間不會自動重算。備註、清單勾選也會保留。清除瀏覽器資料後，本機順序與備註可能消失。

若要更新全家看到的行程，仍需修改 data.js 並上傳 GitHub。本版沒有景點照片，無須上傳 assets 資料夾；舊資料夾即使留在 GitHub 也不會再顯示。

## 每日天氣

使用 Open-Meteo Forecast API（https://open-meteo.com/en/docs），需連網。每天對應當天旅遊區域座標：市區、徐匯、朱家角或嘉定。

- 預報最長約16天，超出範圍明確顯示「尚未進入預報範圍」，不以現在天氣或歷史平均冒充旅行日預報。
- 進入範圍後，開啟網頁或按更新會取得高低溫、天氣、最大降雨機率、最大風速。
- 本次2026/12/4–12/9，通常約11/19起陸續進入範圍，最後一天約11/24起進入範圍，實際依服務回傳。
- 查詢失敗會顯示錯誤並可重試，行程不受影響。過去日期不顯示目前預報。
- 網頁關閉時不在背景更新；下次開啟會更新。中國大陸網路可能無法順利連到部分境外服務，出發前試用。
- Open-Meteo 免費服務適用非商業用途與其使用限制；商業用途需自行確認授權。畫面保留來源署名。

## 本機預覽

可直接雙擊 index.html 查看。若瀏覽器限制本機請求，在此資料夾執行 `python3 -m http.server 8080`，然後開啟 http://localhost:8080 。

## 驗證

`node --check app.js` 與 `node --check data.js` 檢查語法。無外部字型或建置步驟；無外部圖片依賴。建議首次部署後在手機確認天氣連線、導航與所有日期。

## 手機版排版

字體已恢復放大前的大小。住宿卡片的地圖連結另放一列，插畫說明放在圖片下方，手機行程右側保留32px按鈕空間，兩顆按鈕間距16px。載入檔案附版本參數以減少舊快取混用。
